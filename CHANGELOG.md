# Changelog

## 0.1.0 (2026-10-25)

First release. It covers the api.email API as documented at https://api.email/docs/api:

- emails: `send`, `get`, `list`, `listAll` and `cancel`;
- domains, routes, inbound messages with attachment downloads, and webhooks;
- `verifyWebhook` for signed webhook and route deliveries.
